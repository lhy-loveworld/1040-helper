# Remote work and multistate triage

Use this module after a move, remote work across state lines, multiple state wage boxes, work travel, or equity earned while working in more than one jurisdiction.

This skill's default output identifies federal implications and potential state filing work. Prepare a state return only when the user explicitly adds it to scope and the exact-year official state forms and instructions are available.

## Build the timeline

Collect:

- Domicile and residence locations with move dates.
- Physical work locations by period; do not equate an employer office or mailing address with where services were performed.
- Employer legal/payroll location and every W-2 state/local wage and withholding box.
- Dates and locations for material work travel.
- Estimated payments, extensions, prior-year credits, and state notices.
- For equity compensation, grant, vest/exercise, and sale dates plus work locations over the state-required sourcing period.

Ask for a calendar summary rather than day-by-day detail unless an applicable state's method requires workdays.

## Analyze separately by jurisdiction

For each potentially involved state, retrieve that tax year's official resident, part-year resident, or nonresident instructions. Determine filing status, residency period, income-sourcing rule, remote-work rule, allocation method, reciprocal agreement, and credit-for-taxes-paid mechanics from that state's primary sources.

Do not assume:

- W-2 state wages are correct merely because they were reported.
- Withholding creates or eliminates a filing obligation.
- Federal sourcing rules apply to a state.
- Every state treats remote work or equity compensation the same way.
- The same income can be removed from both states rather than handled through allocation or a credit.

Record federal and state work as separate calculations and reconcile all state withholding. If the work-location history, equity sourcing period, residency/domicile facts, or another state's final tax is not available, leave the state result unresolved and recommend a state specialist.
